# Home

Shelf opens on **Home**, a collection overview. It is deliberately separate from **Browse**: Home answers “what is happening in my library?”, while Browse remains the place for searching, filtering, sorting and bulk editing.

Home shows:

- catalogue, owned and wishlist totals;
- items currently lent out;
- missing-cover count;
- the media types currently present in the collection;
- a media-type breakdown;
- recent additions;
- direct links to Browse, Series and Statistics.

Editors and administrators also get a **Scan item** shortcut. Viewers see the same read-only overview without mutation controls.

No new dashboard data is stored. The page is built from the existing catalogue, checkout and cover state each time it is opened.
