Sync imports your audiobooks and ebooks from Audiobookshelf into Shelf, including metadata and cover art. It also auto-links digital items to matching physical books in your collection.

Hardcover

Connecting to Hardcover

  1. Create a free account at hardcover.app
  2. Go to Account Settings → Hardcover API
  3. Copy the API token shown at the top of the page
  4. Paste it into the field below and click Test

What does Hardcover do?

Hardcover is a modern book tracking platform (like Goodreads). With an API token, Shelf can use Hardcover as a metadata source for richer book data including series info, descriptions, and cover art. Future updates will add library import/export and reading status sync.

The API is completely free. Tokens expire after one year.

Collection Valuation

Getting an ISBNdb API Key

  1. Go to isbndb.com and create an account
  2. Subscribe to a plan that includes API access (Basic or higher)
  3. Navigate to your account dashboard and find the API Keys section
  4. Generate a new key, copy it, and paste it into the field below

About ISBNdb

ISBNdb is a book metadata service that provides publisher list prices (MSRP). These prices are used to estimate the replacement value of your collection for insurance purposes.

API access requires a paid subscription (Basic plan: $14.99/month or $149/year). Valuation results are cached for one year, so you can subscribe monthly, valuate your collection, then cancel — subsequent runs will use cached prices.

Google Books

Getting a Google Books API key

The key comes from Google Cloud, not from a Google Books account.

  1. Open the Google Cloud console and select a project, or create one — a personal project is fine and the Books API needs no billing
  2. Enable the Books API for that project
  3. Go to APIs & Services → Credentials → Create credentials → API key and copy the key
  4. Recommended: Edit API key → API restrictions → Restrict key → Books API, so a leaked key can do nothing else
  5. Paste it below and press Test Key before saving

Why bother?

Anonymous Google Books requests are rate-limited per source IP address, and that budget is shared with everyone else calling from the same address. A key gives you a quota of your own.

Google Books is the last book source tried on an ISBN scan, behind Open Library and Hardcover, so a key matters most if your scans often come back thin or you run bulk operations like the synopsis backfill.

Do not set an HTTP referrer restriction — Shelf calls the API from the server, not the browser, and a referrer restriction rejects every request.

Optional. Google Books continues to work anonymously without a key. When configured, the key is used only for Google Books API requests.

Stored encrypted and sent only in the X-Goog-Api-Key request header.

Movie Database (TMDb)

Getting a TMDb credential

  1. Go to themoviedb.org and create a free account
  2. Go to Settings → API in your profile
  3. Request access (select "Developer" — it's instant for personal use)
  4. Copy either credential shown and paste it below: the 32-character API Key (v3 auth) or the long API Read Access Token (v4 auth). Shelf detects which one you pasted.

About TMDb

The Movie Database (TMDb) provides movie and TV metadata including poster art. It's used when you scan DVD or Blu-ray UPC barcodes — Shelf looks up the UPC to get the title, then fetches metadata and poster from TMDb.

TMDb's API is free for personal use with generous rate limits.

IGDB (Video Games)

Getting IGDB Credentials

  1. Go to dev.twitch.tv/console and log in with a Twitch account
  2. Click Register Your Application
  3. Set any name, use http://localhost as the OAuth redirect, and category Application Integration
  4. Copy the Client ID from the app listing
  5. Click New Secret to generate a Client Secret

About IGDB

IGDB (Internet Game Database) is the community standard game database, owned by Twitch. It provides game metadata, cover art, platform info, and more. Authentication is via Twitch developer credentials (free).
