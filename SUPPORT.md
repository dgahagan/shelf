# Getting help

- **Docs:** [docs/](docs/README.md) — installation, configuration, a full
  user guide, [FAQ](docs/faq.md) and [troubleshooting](docs/troubleshooting.md).
- **Bugs:** [open an issue](https://github.com/dgahagan/shelf/issues/new/choose)
  with your Shelf version, browser/device and relevant log lines
  (Settings → Logs, or `docker compose logs shelf`).
- **Feature requests:** same place, using the feature-request template.
  The roadmap follows the maintainer's own library first, but reported
  needs shape it — several shipped features started as user issues.
- **Security problems:** please **don't** open a public issue — use
  [private vulnerability reporting](https://github.com/dgahagan/shelf/security/advisories/new).
  See [SECURITY.md](SECURITY.md).

Shelf is a personal project shared as-is under AGPL-3.0; there is no SLA, but
issues are read and answered.
